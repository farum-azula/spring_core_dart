## Unreleased

- The README describes the HTTP service clients as built (no longer "in a later release") and the build error for an interface that another starter implements too (`@InterfaceProxy`).
- First release: Spring Boot's `spring-boot-starter-restclient` for the family. The `RestClientBuilder` bean (a new one for each injection, prototype as in Spring Boot), set up by the `restClientBuilderConfigurer` bean from the `httpTransport` bean, the application's `ObjectMapper`, `spring.http.clients.*` (`connect-timeout`, `read-timeout`, `redirects`) and the `RestClientCustomizer` beans in their order.
- HTTP service groups: `spring.http.serviceclient.<group>.*` (`base-url`, `default-header`, `connect-timeout`, `read-timeout`, `redirects`), the `HttpServiceGroup` beans (which the generator declares for `@ImportHttpServices`), the `RestClientHttpServiceGroupConfigurer` beans, and the `httpServiceGroups` bean with `restClient(group)`; an unknown group is an error naming the property to set.
- **Security:** the `httpTransport` bean calls only the addresses allowed by hand: `spring.http.clients.allowed-addresses` and the hosts of the groups' base URLs (`httpClientAllowedAddresses`, an `AllowedAddresses` bean an application may replace, narrowed by an `InetAddressFilter` bean). Private networks, loopback and cloud metadata are denied unless listed; on `dart:io` the resolved address is the one checked and connected to, on each redirect too. There is no property to switch it off; `*` allows any host with a public address.
- `AllowedAddressesContributor` beans add to the allow list what another starter was given by hand (the OAuth2 client's provider endpoints).
- With `spring.resilience.enabled: true`, the `eventStreamRetryAdapter` bean (`springBootStarterRestclientResilienceAutoConfiguration`): a `@Retryable` method that returns an `EventStream` stays an `EventStream` when retried. Without the switch the build has none of it.
- HTTP service clients: the generator implements each interface an `@ImportHttpServices` imports with the `RestClient` calls of its exchange annotations written out, a bean on the client of its group (`HttpServiceGroups.restClient`), with an `HttpServiceGroup` bean per group; see the README's "HTTP service clients".
