# flutter_counter

The counter app of `flutter create`, on [`spring_boot_starter_flutter`](../../spring_boot_starter_flutter/README.md).
Same screen, but:

| File | What it shows |
|---|---|
| `lib/main.dart` | `@SpringBootApplication` on `main`, `SpringApplicationWidget(home: CounterPage())`: no hand-written `MaterialApp` |
| `lib/src/counter/counter.dart` | the count is a bean instead of a `State`: `@ChangeNotifierComponent` (no `extends ChangeNotifier`, no `notifyListeners()`) |
| `lib/src/counter/counter_properties.dart` | `@ConfigurationProperties('counter')`: title and step, validated at startup (`@Min`, `@SizeConstraint`) |
| `lib/src/counter/counter_page.dart` | the page, a `SpringStatelessWidget<(CounterProperties, AppAssets, Counter)>`: it only calls `counter.increment`, so a tap does not rebuild it; texts via `context.message(...)` |
| `lib/src/counter/counter_value.dart` | a `SpringStatelessWidget<(Counter,)>` that reads `counter.value` in build: the only widget a tap rebuilds |
| `lib/src/about/app_assets.dart` | assets injected into a bean: `@Value('asset:assets/images/leaf.png') Resource logo` (shown with `AssetImage(key)`) and a text read with `readAsString()`, its Japanese file found with `createRelative` |
| `lib/src/about/about_page.dart` | the About page (the app bar's ⓘ button): a `SpringStatelessWidget<(AppAssets,)>`: the logo and the text |
| `lib/src/lifecycle_log.dart` | the app lifecycle as application events (`@EventListener`), logged through a `log` getter generated by `@Log` |
| `lib/resources/application*.properties` | defaults and a title per platform profile (`mobile`, `desktop`, `web`); the app widget: `spring.flutter.app.type=material`, title, no debug banner; the theme: `spring.flutter.theme.seed-color`, a fallback font |
| `lib/resources/messages*.properties` | the texts in English and Japanese |
| `assets/images/`, `assets/texts/` | the app's assets (`flutter: assets:` in `pubspec.yaml`): the logo and the About texts |
| `test/widget_test.dart` | the template's test with `springBootTest`, and with `SpringApplicationWidget` itself |
| `test/golden_test.dart` | screenshots of the app (`test/goldens/*.png`): start, after taps, Japanese, the About page (English and Japanese), desktop |

## Run

```sh
flutter run                                      # any device
flutter run --dart-define=COUNTER_STEP=5         # a property at build time
```

After changing beans or annotations, regenerate `lib/main.spring.dart`:

```sh
dart run build_runner build      # or `watch` while developing
```

## Screenshot tests

`test/golden_test.dart` starts the app with `SpringApplicationWidget` and compares each
screen with its PNG in `test/goldens/`, with real fonts (Roboto and the
Material icons of the Flutter SDK) so the PNGs are readable. When a screen
changes, the test fails and `test/failures/` shows the expected image, the
actual one and the difference (in CI: the `golden-failures` artifact of the
`goldens` job).
A change on purpose is accepted with:

```sh
flutter test test/golden_test.dart --update-goldens
```

Tests see no system fonts, so the Japanese glyphs come from
`test/fonts/NotoSansJP-Subset.otf`: only the characters of
`messages_ja.properties` and `assets/texts/about_ja.txt`, cut from Noto Sans JP (SIL Open Font License,
`test/fonts/NotoSansJP-OFL.txt`). After changing the Japanese texts, cut it
again ([fonttools](https://github.com/fonttools/fonttools)):

```sh
pyftsubset NotoSansJP-Regular.otf --layout-features='*' \
  --text="$(sed -n 's/^[^=]*=//p' lib/resources/messages_ja.properties)$(cat assets/texts/about_ja.txt)" \
  --output-file=test/fonts/NotoSansJP-Subset.otf
```

The images are made on macOS and only match on macOS: Linux and Windows
draw the letters differently (0.5–3% of the pixels of a screen with text,
more than a changed digit). So CI compares them on a macOS runner, the file
is tagged `golden`, and elsewhere it is left out with
`flutter test --exclude-tags golden`. Small differences between macOS
versions (0.5% of the pixels) are tolerated (`test/flutter_test_config.dart`).
